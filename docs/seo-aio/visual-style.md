# MEAT PLUSの見た目の方針

ユーザー指定（2026-11-04）：情報はまじめで信頼できる内容にし、見た目は華やかで楽しく、色鮮やかで美しいものにする。ベージュ背景に寄せない。

## 基準

- 基本背景は白。濃いネイビーを本文に使い、説明の読みやすさを確保する。
- コーラルレッド、ターコイズ、黄色、紫を、カテゴリ・図解・写真のフレームなどに配色する。すべての文字を多色にしない。
- 彩度のある面やシンプルな形で華やかさを出し、商品写真の色そのものは変えない。
- 詳細情報の領域は白地と余白を確保し、要点・図解・写真で流し読みできる構成を維持する。
- 正確な商品情報、出典、構造化データ、購入リンク・計測を装飾と独立して維持する。

## 配色と確認

主要なボタン色は白文字に対して、コーラル #d92d49 約4.75:1、ターコイズ #007c83 約4.99:1、紫 #6650cb 約5.87:1。淡色面の小さな見出しやリンクはさらに濃い色を使用する。これは主要色の計算値であり、全組み合わせの適合認証ではない。
