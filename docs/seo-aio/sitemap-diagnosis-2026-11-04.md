# サイトマップ診断（2026-11-04）

## 確認できた事実

- LPのsitemap.xmlには83 URL（商品・用途・カテゴリ・記事10件と記事一覧など）が含まれている。W2向けw2-sitemap.xmlは61 URL。
- Search Consoleのサイトマップ一覧は両方とも「取得できませんでした」、検出0の表示が残る。最終読み込み欄が空であることだけから、未試行か失敗かを断定しない。
- sitemap.xml自体の公開URLテスト（17:20 JST）では、クロール許可「はい」、ページ取得「成功」、HTTPレスポンス200 OK、Content-Type application/xmlをGoogle検査ツールの画面で確認。取得ソースにもXMLと商品URLが表示された。これは通常のサイトマップ処理の成功とは区別する。
- `/articles/` と `/articles/beef-cuts/` で登録リクエストが受理され、優先クロールキューへの追加を確認。インデックス登録完了とは扱わない。XMLファイル自体の検索登録は依頼していない。

## 修正

PR #14：トップ・運営者・カテゴリのlastmodをビルド日で毎日更新する処理を廃止。実際の更新日を確認できないページはlastmodを省略する。商品は有効な元の更新日時がある場合だけ記載する。商品ページのWebPage構造化データは最新の商品名・更新日時へ更新し、本文とProduct構造化データを保持する。

新しい回帰テストを含むNode 9件、60商品・4用途ガイドの検査と10記事の生成を確認。公開ワークフローの設定は変更せず、回帰テストは `node --test scripts/test-discovery-metadata.mjs` で実行する。

## 未確定

公開URLテストの成功は、サイトマップレポートの失敗表示が解消したことを意味しない。今回の更新日・WebPage修正が取得失敗の原因を直したとも断定しない。URL別名を増やしたり、理由なくファイル形式・ドメイン・公開フローを変更したりせず、公開結果とGoogleの処理状況を分けて確認する。
